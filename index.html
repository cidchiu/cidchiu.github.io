Bay Area Incident Reports Map

February 2026

The BAIRS map is designed for the Caltrans District 4 Dispatch Center. It includes both a map and a Unit Table to help staff quickly identify the responsible unit for different areas of the state highway system. The map provides two search options: one to search by address or place, and another to search by County, Route, and Postmile. These tools allow dispatch staff to quickly locate the appropriate unit number responsible for a specific area. Once the unit number is identified, staff can use the Unit Table to look up the corresponding contact person and information needed to respond to incidents on the state highway system.

Survey 123 App - Project based

February 2026

Another Survey123 app has been created to help the public learn about the study and its projects. This app works like a landing page with basic information about the study and an interactive map of the proposed projects. On the left side of the screen, users can see a list of projects, while the map shows where each project is located. People can click on a project name in the list or select it directly on the map. When a project is selected, a window will appear with more information about the project and a button that lets users take a survey specifically about that project.

Survey 123 App to gather public comments

February 2026

Our office is developing a study for State Route 17 and needs a Survey123 survey to collect feedback from stakeholders and the general public. The survey must support map-based input so participants can provide location-specific comments. The survey is built using a question-based (branching) format: the first question presents three options, and the participant’s selection determines which follow-up questions, maps, and project information are displayed. The three options are:

  1. Comment on an existing project concept
  2. Suggest a new project
  3. Provide general comments

Option 1: Comment on an existing project concept If the participant selects Comment on an existing project concept, a drop-down list of approximately 90+ projects is displayed. A map and legend also appear, showing the projects as red points. When a participant clicks a red point, Survey123 captures the project name and description. This automatically links the submitted comment to the selected existing project, making it easy to identify which responses relate to which project concepts.

Option 2: Suggest a new project If the participant selects Suggest a new project, a blank map is displayed. The participant can place a point on the map to indicate the location of their suggested project. Follow-up questions are then used to collect the details of the suggestion.

Option 3: Provide general comments If the participant selects Provide general comments, no map is shown. Instead, the survey displays general questions to collect non-location-specific feedback.

Spatial analysis of A 1,000-foot buffer was applied to all projects to make it easier for the public to select a project within the survey interface. The Survey123 app also includes built-in reply capabilities and supports multiple languages, including Spanish, Chinese, and Vietnamese.
